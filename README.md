## 📚 Contents

### 🔹 Lab Modules

Each module focuses on different core concepts of operating systems and includes individual and group exercises.

- `Module-01`: Introduction to linux, basic command line operations, shell scripting, automation using cron jobs
- `Module-02`: Process, Thread, and IPC
- `Module-03`: Operating system booting
- `Module-04`: FUSE (Filesystem in Userspace) and Simple kernel

### 🔹 Final Project

Our final project is creating simple operating system that brings together all of the knowledge and skills we developed during the lab modules. The project was developed from scratch and simulates OS-like behavior through modular, testable components. It showcases how fundamental OS concepts can be integrated into a cohesive, functioning system.

### 📁 Final Project Structure
- assets: Boot sector images, filesystem illustration, structure of the components, etc.
- bin: Compiled binaries and system boot image
- include: Header files and constant definitions
- src: Kernel source code and system modules
- test: Test routines and simulations
- Makefile: Build system for assembling and compiling the OS
- bochsrc.txt: Bochs configuration file
- README.md: Project overview and instructions
